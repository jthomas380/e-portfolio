# JET380 — Jason E. Thomas

Static portfolio for Jason E. Thomas at https://jet380.com/. Built with HTML,
CSS, JavaScript, and a canvas matrix animation. No build step is required.

## Local preview

Run `python3 -m http.server 8765` from the repository, then open
http://localhost:8765/. Check desktop and mobile layouts and keyboard navigation.

## Résumé

All résumé links open `assets/Jason E Thomas - Front-End Developer Resume.pdf`.
The PDF is the résumé; there is no separate résumé page.

## Review and publishing

Changes on `portfolio-update-2026-10-22` are proposed through a pull request into
`main`. Jason E. Thomas reviews and merges before publishing. Hosting is managed
separately; do not upload changes before review. Back up hosting files before
an approved upload, and include the stylesheet, components, assets, robots.txt,
and sitemap.xml with index.html.
